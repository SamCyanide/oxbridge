How a push becomes a live page

The dashed line is the trust boundary. Everything left of it is GitHub; everything right is AWS. What crosses is a short-lived token and a short-lived credential — never a stored key.

  1. 01The runner asks GitHub for an OIDC token. This needs id-token: write — without it there is nothing to exchange.
  2. 02STS verifies the token's signature against the registered provider, then tests its aud and sub claims against the role's trust policy. Only then is a session issued.
  3. 03The session resolves the bucket and distribution from the CloudFormation stack's outputs, then syncs site/ — nothing is copied into GitHub configuration.
  4. 04One invalidation path, /*, counts as a single path against the 1,000 free each month.

The claim that decides everything

Step 02 is where this design nearly failed. GitHub issues immutable subject claims that embed numeric owner and repository ids — so the subject is not the repo:OWNER/REPO string that almost every published example shows.

Defined in CloudFormation

One stack owns every AWS object above. GitHub-side configuration is a single repository variable holding the role ARN; everything else is read from stack outputs on each run, so nothing can drift.

  • AWS::S3::BucketPrivate, versioned, SSE-S3, non-current versions expire after 7 days
  • AWS::S3::BucketPolicyDenies non-TLS; allows only CloudFront, pinned by SourceArn
  • AWS::CloudFront::OriginAccessControlSigV4 signing between distribution and bucket
  • AWS::CloudFront::DistributionTLS termination, HTTP→HTTPS, PriceClass_100
  • AWS::IAM::OIDCProviderGitHub as a federated identity provider; no pinned thumbprint
  • AWS::IAM::RoleTrust pinned to this repository and branch; four scoped actions
  • AWS::Budgets::Budget$1/month tripwire on actual and forecast spend

Account identifiers are redacted as <account>. Sitting inside the AWS free tier: CloudFront's 1 TB egress allowance is perpetual, S3's 5 GB is twelve months. Exceeded only past 1,000 deploys per month, where each further invalidation path costs $0.005.
